### 🚀 Projects Overview

</div>

#### 📈 Time Series & Financial Forecasting
* **AAPL Attention LSTM** (`aapl_lstm.ipynb`): A deep learning model that predicts the adjusted close price of Apple stock. It utilizes an LSTM model augmented with an Attention mechanism, allowing for time-based weighting of historical data to yield highly accurate results.
* **WTI Crude Oil Forecasting** (`forecasting using NNs`): A Jupyter notebook implementing deep learning techniques to predict WTI crude oil prices.
* **Weather Station Prophet** (`fbprophet`): A multi-series forecasting project utilizing `fbprophet` to model and predict data across different weather stations in China.
* **Cloud-Deployed Stock Dashboard** (`.zip`): A full-stack deployment displaying a stock dashboard with dynamic JSON charts. It includes an endpoint deployed via AWS SageMaker for predicting the next day's closing price.

#### 🧮 Quantitative Models & Mathematics
* **Spread Modeling** (`modelling/`): Implements a simple linear regression model for `med_spread` prediction. The quantitative logic and approach are fully documented in the included `answers.txt` file.
* **Stochastic Random Walks** (`randomwalk.py`): A Python implementation of Monte Carlo simulated random walks, useful for modeling asset paths and random processes.
* **Robust Multivariate Mean Testing** (`766_Assignment/`): Re-evaluates robust multivariate mean testing via the reweighted minimum covariance determinant (MCD) estimator, providing a fully reproducible replication of the simulation study in Willems et al. [2002]. Building on the statistic $T^2_R = n (T_1-\mu_0)^\top C_1^{-1} (T_1-\mu_0)$, the project calibrates its small-sample null distribution by moment-matching to a scaled F law, $T^2_R \approx d \cdot F_{p,q}$, and reports fitted parameters $(d, q)$ across $(n, p)$ grids.

#### 🧠 Applied Machine Learning
* **Audio Classification** (`audio classification/`): Leverages a pre-trained model alongside self-implemented clustering algorithms to effectively process and classify audio files.
